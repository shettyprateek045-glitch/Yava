    Why Decision Threshold Tuning Matters

    At the standard 0.50 cutoff, the model recall collapses to just 5.1% (missing 95% of actual churners). By optimizing the decision threshold to 0.206, the model catches 81.4% of at-risk subscribers. For retention operations, reviewing an expanded list is far cheaper than permanently losing annual subscription ARR.

    About Yava Retention Console

    Yava is an end-to-end Data Science & Machine Learning portfolio project for streaming subscription retention.

    • Dataset: 5,000 synthetic subscriber records generated with realistic distributions (tenure, streaming habits, inactivity, and ticket friction).
    • Models: Baseline Logistic Regression (v1) and Stacking Ensemble with Random Forest & LightGBM (v2).
    • Decision Optimization: Tuned operational cutoff (0.206) maximizing recall (81.4%).
    • Product Layer: FastAPI REST API + dark-mode instrument panel + SQLite prediction audit logging + What-If simulation engine + Feature Drift Monitor + Financial ROI Matrix.
